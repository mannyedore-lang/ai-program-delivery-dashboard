# AI Program Delivery Dashboard

A portfolio-style demonstration of how a Technical Program Manager can govern multiple AI initiatives from intake through production.

## Business Problem

AI programs often span engineering, data, security, legal, product, and operations. Leadership needs one view of delivery health, risk, dependencies, and business value.

## What This Project Demonstrates

- Program intake and prioritization
- Milestone and dependency tracking
- AI-specific risk and readiness checkpoints
- Executive KPI reporting
- Delivery health scoring
- Value-realization tracking

## Sample KPIs

- % milestones on time
- Critical dependency count
- Open high-severity risks
- Production-readiness status
- Budget variance
- Business value delivered
- Model quality / reliability readiness

## Files

- `data/ai_programs.csv` — sample program data
- `src/dashboard_metrics.py` — portfolio KPI calculations
- `governance/launch_readiness_checklist.md` — launch readiness framework
- `governance/risk_register_template.csv` — reusable risk register
